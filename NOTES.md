# Список команд
1. dotpack scan - ищет конфиги в системе

2. dotpack link - делает симлинки конфигов из репозитроия в нужные места в системе

3. dotpack update - смотрит конфиги в системе и в репо, если они различтаются предлагает обновить (Сообщение - конфиги в репо и в системе отличаются хоите перезаписать? 1. Перезаписать в репо из системы (если нет симлинка) 2. Перезаписать в систему из репо 3. Не перезаписывать + сообщение о пропуске)

4. dotpack push - полностью обновляет конфиги на гите (add, commit, push)


# Вид конфигов в файле (1 столбец - путь, 2 - симлинк в репо)
~/.config/kitty/kitty.conf    ->   kitty-conf
~/.zshrc                      ->   zshrc-conf


# Архитектура
Файлы:
- src/main.cpp       - Общий сбор всех комманд
- src/config.cpp/.h  - Париснг конфигов
- src/commands/      - содержит в себе всю логику команд
    scan.cpp/.h
    link.cpp/.h
    update.cpp/.h
    push.cpp/.h

Функции:
- main            - вызывает нужной команды по argv
- scan
- link
- update
- push

Коды ошибок:
0 - успешно
1 - ошибка filesystem
2 - неверные аргументы
3 - команда не найдена
